# AI 작업 기록

AI(Claude Code)가 쓴 코드에서 실제로 나온 문제와 수정 과정을 날짜순으로 남깁니다. 없었던 일은 쓰지 않습니다.

## 2026-11-05 · DB 연결을 닫지 않는 CLI

**증상**: 전체 테스트 17개 중 3개가 `PermissionError: [WinError 32]`로 오류. 임시 폴더를 지우려 할 때 `source.db`, `target.db`가 다른 프로세스에서 사용 중이라는 오류였습니다.

**원인**: AI가 작성한 CLI 명령(`profile`, `plan`, `apply`, `baseline`, `verify`)이 SQLite 연결을 열고 닫지 않았습니다. Linux에서는 가비지 컬렉션에 가려지고, Windows에서는 파일 잠금으로 드러납니다.

**수정**: 모든 명령에서 `contextlib.closing`으로 연결을 닫도록 변경했습니다. 수정 후 17개 전부 통과했습니다.

**배운 점**: 정상 경로만 보면 지나치기 쉬운 자원 누수가 테스트 정리 단계에서 드러났습니다. 테스트가 임시 파일 삭제까지 포함해 돌아가야 이런 문제가 잡힙니다.
